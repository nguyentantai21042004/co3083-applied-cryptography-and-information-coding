Hướng dẫn giải bài toán Diffie-Hellman Key Agreement (DHKA)
1. Kiến thức cơ bản
Diffie-Hellman Key Agreement là gì?

Là giao thức cho phép Alice và Bob thỏa thuận một khóa bí mật chung qua kênh công khai
Kẻ nghe lén chỉ thấy các giá trị công khai nhưng không thể tính được khóa chung

Các bước thực hiện:
Công khai: p (số nguyên tố lớn), g (cơ số)
Alice:

Chọn khóa bí mật: a (ngẫu nhiên)
Tính giá trị công khai: A = g^a mod p
Gửi A cho Bob

Bob:

Chọn khóa bí mật: b (ngẫu nhiên)c
Tính giá trị công khai: B = g^b mod p
Gửi B cho Alice

Khóa chung:

Alice tính: K = B^a mod p
Bob tính: K = A^b mod p
Cả hai có cùng khóa: K = g^(ab) mod p

3. Phương pháp giải
Phương pháp 1: Tìm khóa bí mật a hoặc b (Brute Force)
Bước 1: Giải phương trình logarit rời rạc

Tìm a sao cho: 2^a ≡ 114088419126 (mod 461733370363)
HOẶC tìm b sao cho: 2^b ≡ 276312808197 (mod 461733370363)

Bước 2: Tính khóa chung

Nếu tìm được a: K = B^a mod p
Nếu tìm được b: K = A^b mod p

Thuật toán:
FOR x = 1 TO một_giá_trị_lớn:
    Tính result = 2^x mod 461733370363
    IF result == 114088419126:
        a = x
        Tính K = 276312808197^a mod 461733370363
        RETURN K
    IF result == 276312808197:
        b = x
        Tính K = 114088419126^b mod 461733370363
        RETURN K

Phương pháp 2: Baby-Step Giant-Step (Hiệu quả hơn)
Để giải g^x ≡ h (mod p), với độ phức tạp O(√p):
Bước 1: Chọn m = ⌈√p⌉
Bước 2: Baby steps - Tạo bảng

Tính g^0, g^1, g^2, ..., g^(m-1) mod p
Lưu vào bảng: {g^j mod p : j}

Bước 3: Giant steps

Tính c = g^(-m) mod p = g^(p-1-m) mod p (theo định lý Fermat)
FOR i = 0 TO m-1:

γ = h × c^i mod p
IF γ có trong bảng tại vị trí j:

RETURN x = i×m + j






Phương pháp 3: Pollard's Rho (Cho số lớn)
Thuật toán xác suất với độ phức tạp O(√p):

Phức tạp hơn nhưng tiết kiệm bộ nhớ
Thường dùng trong thực tế mật mã


4. Công thức tính toán quan trọng
4.1. Lũy thừa modulo (a^b mod m)
Thuật toán: Bình phương lặp (Square and Multiply)
Hàm power_mod(a, b, m):
    result = 1
    a = a mod m
    WHILE b > 0:
        IF b lẻ:
            result = (result × a) mod m
        b = b ÷ 2
        a = (a × a) mod m
    RETURN result
Ví dụ: Tính 2^19 mod 461733370363
19 = 10011₂ (nhị phân) = 16 + 2 + 1

Bước 1: Tính 2^1, 2^2, 2^4, 2^8, 2^16 mod p
- 2^1 = 2
- 2^2 = 4
- 2^4 = 16
- 2^8 = 256
- 2^16 = 65536

Bước 2: Nhân các số tương ứng với bit 1
2^19 = 2^16 × 2^2 × 2^1 mod p
4.2. Nghịch đảo modulo (a^(-1) mod m)
Dùng định lý Fermat nhỏ: Nếu p nguyên tố
a^(-1) ≡ a^(p-2) (mod p)

5. Giải bằng máy tính Casio
⚠️ Hạn chế của máy Casio:

Không thể xử lý số lớn (> 10^10)
Không có hàm modulo lũy thừa
Không đủ bộ nhớ để lưu bảng

Cách giải (nếu a hoặc b nhỏ < 100):
Bước 1: Thử từng giá trị
x = 1: Tính 2^1 mod p, so sánh với A và B
x = 2: Tính 2^2 mod p, so sánh với A và B
x = 3: Tính 2^3 mod p, so sánh với A và B
...
Bước 2: Khi tìm được x = a (hoặc b)
K = B^a mod p  (hoặc A^b mod p)
Cách tính a^b mod m trên Casio:
1. Chuyển b sang nhị phân
2. Tính các giá trị a^(2^i) mod m
3. Nhân các giá trị tương ứng bit 1
4. Lấy mod m sau mỗi phép nhân

6. Giải bằng Python/Code
pythondef power_mod(base, exp, mod):
    result = 1
    base = base % mod
    while exp > 0:
        if exp % 2 == 1:
            result = (result * base) % mod
        exp = exp >> 1
        base = (base * base) % mod
    return result

# Dữ liệu
p = 461733370363
g = 2
A = 114088419126
B = 276312808197

# Tìm a hoặc b (brute force cho số nhỏ)
for x in range(1, 1000000):
    if power_mod(g, x, p) == A:
        print(f"a = {x}")
        K = power_mod(B, x, p)
        print(f"Shared Key K = {K}")
        break
    if power_mod(g, x, p) == B:
        print(f"b = {x}")
        K = power_mod(A, x, p)
        print(f"Shared Key K = {K}")
        break

9. Lưu ý bảo mật
